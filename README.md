# Indalbo landing-page review

Public design preview: https://shijon12.github.io/indalbo-landing-preview/

This is a separate review copy, not the production Indalbo website.
The interaction is a scripted illustration, not live AI or real tool execution.
Long-running ownership is labelled under test, not live.

Waitlist fields are disabled. No submissions, backend, contact records or
credentials are included. Search indexing is discouraged, but this repository
and its hosted website are public and are not access-controlled.

GitHub Pages publishes the root of the main branch. No build step is needed.
Relative asset and navigation paths support the repository subdirectory URL.
Original work remains in the separate indalbo-landing workspace.
