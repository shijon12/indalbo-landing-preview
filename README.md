# Indalbo landing-page review

Public design preview: https://shijon12.github.io/indalbo-landing-preview/

This is a separate review copy, not the production Indalbo website.
The interaction is a scripted illustration, not live AI or real tool execution.
Long-running ownership is labelled under test, not live.

The waitlist collects only an email address and posts directly to FormSubmit,
forwarding signups to support@indalbo.com. The owner must activate the form from
that inbox after an initial submission and verify delivery before sharing it as
a working signup funnel. Provider reCAPTCHA is enabled. No backend, contact records
or credentials are included in this repository. Search indexing is discouraged, but this repository
and its hosted website are public and are not access-controlled.

GitHub Pages publishes the root of the main branch. No build step is needed.
Relative asset and navigation paths support the repository subdirectory URL.
Original work remains in the separate indalbo-landing workspace.

Privacy and Terms reuse the original Indalbo repository's legal text, unchanged.
They are linked from the footer and beside the waitlist. FormSubmit processing
is disclosed separately at the form, with a link to its data-handling policy.
